# CloudVault

CloudVault is a full-stack cloud file storage application designed to provide secure file management, organization, downloads, and file sharing.

The project is being developed as a portfolio application to demonstrate modern full-stack software development practices.

## Tech Stack

### Frontend
- React
- TypeScript
- Vite

### Backend
- Node.js
- Express
- TypeScript

### Database
- PostgreSQL

### Cloud Storage
- AWS S3

### Authentication
- JWT
- bcrypt

### Infrastructure
- Docker
